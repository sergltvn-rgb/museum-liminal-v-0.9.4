# Museum Liminal 1.0.0

Атмосферная хоррор-игра на Godot 4.7 о ночных сменах в музее аномальной физики. Первый запуск начинается с отдельного интерактивного пролога; его всегда можно повторить из главного меню.

## Игровой цикл

1. Осмотрите музей до отключения электричества.
2. После аварии определите повреждённый экспонат и прочитайте протокол.
3. На ночах 2–3 подтвердите конкретный повреждённый экспонат через соответствующую ему камеру.
4. Найдите подходящий стабилизатор и примените его непосредственно к разрыву у экспоната.
5. Пройдите уникальную головоломку внутри открывшегося карманного измерения.
6. Вернитесь с ключом стабилизации и закройте разрыв.

Тип аномалии и её местоположение выбираются независимо: разрыв может захватить любой экспонат в уже открытом крыле. Эффекты локальны — переменная гравитация, темпоральное искажение, радиационное поле или нестабильность света усиливаются при приближении к источнику. Со второй ночи по музею перемещается Куратор — фарфоровый музейный автомат с камерой вместо лица, который приближается, пока не находится в поле зрения игрока.

## Управление

| Действие | Клавиатура | Геймпад Xbox |
|---|---|---|
| Движение | WASD | Левый стик |
| Обзор | Мышь | Правый стик в режиме камер |
| Прыжок / подтверждение | Space / Enter | A |
| Взаимодействие | E | X |
| Бросить прибор | G | B |
| Планшет камер | Tab | Y |
| Фонарик / прожектор CCTV | F | RB |
| Спринт (расходует выносливость) | Shift | Нажатие левого стика |
| Пауза | Esc | Start |

В отдельном интерфейсе настроек доступны вкладки «Аудио», «Графика», «Управление» и «Доступность»: плавная громкость, чувствительность мыши, разрешения 1280×720 / 1600×900 / 1920×1080, качество эффектов, VSync, полноэкранный режим, RU/EN, субтитры, высокий контраст, уменьшение движения и мерцания, крупный интерфейс. Все длинные разделы поддерживают вертикальную прокрутку. Изменения сохраняются автоматически в `user://`.

## Запуск

1. Установите Godot 4.7 с экспортными шаблонами.
2. Если проект обновлялся поверх старой папки, запустите `prepare_godot_47.cmd` — он удалит старые вложенные `project.godot` из `scripts/`, `scenes/`, `models/`, `audio/` и очистит кэш `.godot`.
3. Откройте `project.godot` и дождитесь повторного импорта.
4. Запустите главную сцену `scenes/FirstMuseumMap.tscn`.

## Ручное редактирование карты

Карта больше не пересоздаётся при каждом открытии сцены. Откройте `FirstMuseumMap.tscn`, раскройте узел `GeneratedMap` и меняйте любой объект обычными инструментами Godot: перемещение, вращение, масштаб, дублирование и удаление. После изменений сохраните сцену.

Если нужно полностью отменить ручную расстановку и получить актуальную стандартную карту, выберите корневой узел `FirstMuseumMap` и включите в Inspector параметр **Rebuild Generated Layout**. Переключатель удаляет текущую ручную компоновку, поэтому используйте его только намеренно.

## Проверка и сборка

- `run_tests.cmd` — headless-проверка карты и интеграций.
- `build_release.cmd` — импорт, тесты и Windows release export.
- Готовая Windows-сборка создаётся в `build/windows/MuseumLiminal.exe`.

Пресеты также подготовлены для Linux и Web. Для Web необходимо отдельно проверить поддержку выбранного 3D physics backend экспортным шаблоном Godot.

## Структура

- `game/FirstMuseumMap.gd` — сборка карты;
- `game/GameManager.gd` — цикл ночей;
- `game/GameplayEnhancements.gd` — механики аномалий, CCTV-задачи и Наблюдатель;
- `game/SecurityCameraTablet.gd` — 11 камер, доступных только из офиса охраны;
- `game/InputBootstrap.gd` — клавиатура и геймпад;
- `game/SettingsManager.gd` — пользовательские настройки;
- `game/RiftTrialManager.gd` — тонкий диспетчер карманных измерений;
- `game/trials/` и `scenes/trials/` — реестр и 10 самостоятельных сцен испытаний;
- `game/TutorialPrologue.gd` — интерактивный сектор ориентации;
- `localization/game.csv` — исходный RU/EN-каталог;
- `RIFT_TRIALS.md` — дизайн карманных измерений, открываемых стабилизаторами;

Правильный стабилизатор открывает тематическое карманное измерение: архив с поворотом настоящей гравитации, временную петлю с записываемыми копиями игрока, зал физически перемещаемых радиационных монолитов или пространство с динамической световой геометрией. Только созданный внутри ключ закрывает разрыв.
- `models/` — GLB-экспонаты;
- `textures/museum_map.png` — иллюстрированный план музея для стенда в атриуме;
- `audio/` — музыка окружения и эффекты.

## Производительность

Мелкий декор не создаёт физические тела и не отбрасывает тени. Дальняя декоративная геометрия плавно скрывается. Для слабых GPU рекомендуется отключить volumetric fog, SSAO и glow в настройках проекта перед экспортом.

## Применение приборов

Каждый прибор даёт эффект, пока вы несёте его в руках:

| Прибор | Применение |
| --- | --- |
| Гравитационный якорь | Ключевой прибор для стабилизации гравитационных аномалий (отнести к разрыву) |
| Хроностабилизатор | Ключевой прибор для временных аномалий |
| Стержень сдерживания | Ключевой прибор для радиационных аномалий |
| Полевой излучатель | Ключевой прибор для пустотных разрывов |
| Спектральная линза | Кольца разрыва видны сквозь стены + в HUD показ��но расстояние до него |
| Фазовая призма | Ослабляет влияние аномалии на вас более чем вдвое |
| Резонансный настройщик | Доза облучения набирается вдвое медленнее |
| Зажим массы | Полный иммунитет к искажению гравитации и прыжка |
| Термомел | Оставляет светящуюся дорожку следов — не заблудитесь в темноте |
| Катушка памяти | Один раз за смену даёт +45 секунд к таймеру аномалии |
| Нуль-фонарь | Наблюдатель рядом с вами движется вдвое медленнее |
| Нить возврата | HUD показывает расстояние до разрыва; в ТЁМНОМ СЕКТОРЕ монстр на 25%% медленнее |

В ТЁМНОМ СЕКТОРЕ: ЛКМ — импульс лидара, точки остаются на стенах. Монстр невидим — только красные точки выдают его.

## Карманные измерения (10)

| Аномалия | Измерение | Задача |
| --- | --- | --- |
| Гравитационный скачок | Гравитационный архив | Платформы и якоря смены гравитации |
| Временной сдвиг | Пропавшая минута | Повторите маршрут своего эха по плитам |
| Радиационное цветение | Критическая масса | Расставьте монолиты по гнёздам и частотам |
| Разрыв пустоты | Тёмный сектор | Полная тьма: лидар (ЛКМ), 3 узла, выход, невидимый монстр |
| Резонансное эхо | Эхо-камера | Повторите порядок вспышек 4 колонн (3 раунда) |
| Фазовый провал | Зыбкий мост | Перейдите мост: в каждом ряду одна плита — фантом |
| Зеркальный разлом | Зал отражений | Найдите 3 мерцающих дефектных зеркала |
| Жёлтый предел | Жёлтые залы (по мотивам Backrooms) | Соберите 3 плёнки и найдите выход-разметку |
| Изъятие ценностей | Служба извлечения (по мотивам R.E.P.O. / Lethal Company) | Перенесите 3 хрупких экспоната, не упав в провал |
| Вертикальный разлом | Восхождение (по мотивам PEAK) | Заберитесь по уступам быстрее тумана |

Выпасть за границы измерений невозможно — по периметру невидимые стены.
